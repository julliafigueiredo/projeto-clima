# Previsão do Tempo

Aplicação web moderna e responsiva de previsão do tempo desenvolvida para consulta rápida de condições meteorológicas através do nome da cidade ou CEP.

## Funcionalidades
- **Busca por Cidade ou CEP:** Suporte a consultas diretas de nomes de cidades ou ceps utilizando a BrasilAPI.
- **Autocompletar Inteligente:** Sugestões dinâmicas de cidades enquanto o usuário digita.
- **Modo Noturno (Dark Mode):** Alternância fluida entre tema claro e escuro com salvamento automático de preferência (`localStorage`).
- **Layout Responsivo:** Totalmente adaptado para dispositivos móveis, tablets e computadores.
- **Ícones Dinâmicos:** Renderização de ícones de clima personalizados de acordo com a condição meteorológica atual.

## Tecnologias Utilizadas
- **HTML5** (com tags semânticas)
- **CSS3** (Variáveis CSS, Flexbox, Grid, Media Queries)
- **JavaScript (Vanilla)**
- **APIs Externas:** OpenWeatherMap API & BrasilAPI
